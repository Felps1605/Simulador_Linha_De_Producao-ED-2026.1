# Simulador de Linha de Produção 
Com especificações personalizadas importadas de um arquivo, ao rodar, o programa constrói uma linha de produção de um determinado produto, roda uma simulação de seu funcionamento e retorna os resultados no terminal ou em arquivo

Como usar
  Com todos os arquivos na mesma pasta, execute "main.c"
  Os dados de entrada são obtidos através do arquivo "entrada.txt"
